# Voxtant brand assets

- `app-icon.png`: 1024×1024 RGBA source; the build exports the standard macOS iconset and `.icns`.
- `social-preview.png`: 1280×640 repository/portfolio cover.
- `generation-prompts.json`: exact original, cleanup and cover prompts.

These original assets were created for Voxtant with the built-in imagegen tool on 2026-11-03. Native `sips` resizing produces project exports; `iconutil` packages app icon sizes. The mark combines two speech streams into a cobalt V on pearl glass. No third-party logo or stock asset is included. Assets are distributed with this MIT-licensed repository.

The cover is branding, not an application screenshot. Actual screenshots under `docs/screenshots/` are captured from the app with authored fixture text, without microphone, keys, API calls or desktop contents. The real glass material varies with the user's desktop.

For GitHub Settings → Social preview, use `social-preview.png`. The file is supplied in the repository; storing it here does not itself update GitHub's social-preview setting.
