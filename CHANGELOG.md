# Changelog

## 0.1.0 — 2026-11-03

First packaged experimental macOS demo / Первая упакованная экспериментальная демка.

- Floating, draggable and resizable glass panel with menu-bar access.
- OpenRouter-only Scribe/GPT recognition and a separate text translator.
- Single/mixed language rules and guarded preservation of recognized Chinese spans.
- Progressive translation, independent local audio capture and immediate Stop cancellation.
- Daily recording folders with original audio, transcript, translation and metadata.
- Reported USD costs and approximate dated RUB conversion.
- Local Swift/Python tests, native UI smoke checks and explicit evaluation tooling.
- Voxtant icon, RU/EN documentation and optimized Apple Silicon ZIP/DMG packaging.

No native streaming ASR, notarization, accuracy SLA or long-session readiness claim is included.
